# LAMP Application Hosting on AWS

## Project Overview

This project demonstrates hosting a PHP application on an Amazon EC2 instance using Apache and connecting it to an Amazon RDS MySQL database.

## AWS Services

- EC2
- RDS
- Security Groups

## Tech Stack

- Ubuntu
- Apache
- PHP
- MySQL

## Features

- Apache Web Server
- PHP Application
- Amazon RDS Database
- Employee Records Display

## Architecture

Internet

↓

EC2 (Apache + PHP)

↓

Amazon RDS MySQL
